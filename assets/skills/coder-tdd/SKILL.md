# Coder TDD

Make unit tests and Gherkin acceptance pass for this one story.

- Write a failing test first, then production code. The host does not police keystrokes; finishing a function then testing it is acceptable.
- Messy structure is expected. Do not claim CRAP, mutation, or QA.
- Public surface is the Gherkin. Do not silently change accepted behavior.
- Do not start the next story.
